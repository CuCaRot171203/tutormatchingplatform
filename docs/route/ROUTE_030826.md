## 7. Authentication & Route Guards

### ProtectedRoute (src/components/common/ProtectedRoute.tsx)

- **Role keys chính xác:** `Student`, `Tutor`, `Administrator`
- **DEV_AUTH_DISABLED = true** → bypass hoàn toàn, tất cả route đều accessible
- **Khi bypass OFF** (production):
  1. Unauthenticated → redirect `/login` + lưu `location.state.from`
  2. Wrong role → redirect về role dashboard tương ứng
  3. Correct role → render `Outlet`

### Axios Auth (src/services/api/axios.ts)

- Gửi `Authorization: Bearer <token>` trên mọi request
- `401` → thử refresh token → fail thì logout → navigate `/login`
- `403` → logout → navigate `/login?reason=suspended`

### Auth Store (src/stores/authStore.ts)

- Persisted in `auth-storage` (localStorage)
- Keys: `user`, `accessToken`, `refreshToken`, `isAuthenticated`
- Không có session revalidation on mount

## 8. Current Issues / Observations

### ⚠️ Critical: Auth Bypass Enabled

`DEV_AUTH_DISABLED = true` trong `ProtectedRoute.tsx` khiến toàn bộ route protected thực tế là public. Cần set `false` trước khi deploy.

### ⚠️ Footer Link Bug

Footer dùng `href` thay vì `to` nên các link `/find-tutor`, `/login`, `/subjects`, `/pricing`, `/about` trong `LandingFooter` render thành `#`. Header nav vẫn hoạt động đúng.

### ⚠️ Empty Layout Root Routes

`/student`, `/tutor`, `/admin` không có index redirect → hiển thị layout trống thay vì redirect sang dashboard tương ứng.

### ⚠️ Dormant Loading-Loop Risk

Khi bỏ bypass, nếu user chưa có token và `isAuthenticated = false`, guard sẽ hiển thị loading page mà không redirect tiếp → user kẹt ở loading.

### ⚠️ Milestones Route Inconsistency (Tutor)

`TutorLayout` check URL `/tutor/milestone/...` để highlight menu nhưng route đó không tồn tại.

### ℹ️ Legacy MainLayout

`src/components/Layout/MainLayout.tsx` chứa routes `/student/profile/edit`, `/student/profile/change-password`, `/admin/complaints` nhưng **không còn active** trong router hiện tại.

### ℹ️ ROUTES Constants

`src/config/constants.ts` chứa object `ROUTES` nhưng chỉ cover subset, không được sử dụng active. Nguồn duy nhất: `src/route/urlRoute.tsx`.
