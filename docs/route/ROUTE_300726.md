## 8. ProtectedRoute Logic

```typescript
// src/components/common/ProtectedRoute.tsx

if (DEV_AUTH_DISABLED) return <Outlet />;           // ⚠️ DEV ONLY

if (!token && isAuthenticated === false)
  return <Loading fullPage />;                       // Still loading

if (!isAuthenticated || !user)
  return <Navigate to="/login" state={{ from }} />;  // Not authenticated

if (allowedRoles && !allowedRoles.includes(user.role))
  return <Navigate to={`/${user.role.toLowerCase()}/dashboard` />;  // Wrong role

return <Outlet />;                                  // Authorized
```

## 10. Notes

- **Auth check** hiện đang bị **tắt tạm thời** (DEV_AUTH_DISABLED = true) để xem design.
- Sau khi review xong, bật lại bằng cách đổi `DEV_AUTH_DISABLED = false` trong `ProtectedRoute.tsx`.
- Route thất định: `*` → redirect về `/`.
